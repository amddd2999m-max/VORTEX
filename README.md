# منصة فورتكس | VORTEX V9.0 (Low-RAM & Static Telegram Cover Edition)

# 🌌 مشروع بوت وتطبيق «فورتكس | VORTEX» (النسخة الخاصة الاحترافية V4)

أمر التشغيل الموحد: `python start.py`

## ✨ مميزات نسخة فورتكس (VORTEX)
1. **3 بوتات خفيفة وسريعة جداً (بدون تعقيد البوت الرابع وبدون Telethon):**
   - **بوت فورتكس الرئيسي (`@Vortexee_Bot`)**: واجهة المستخدم بأزرار ملونة (`أحمر / أزرق / أخضر`) ويفتح تطبيق فورتكس المصغر (Mini App).
   - **بوت الإدارة (`Vortex Admin`)**: لوحة تحكم شاملة بالأزرار الملونة بدون حفظ أو كتابة أوامر نصية (`/`):
     - 🔴 **الأحمر (`danger`)**: للأزرار المهمة والأساسية (إضافة عمل، إضافة حلقات، الطلبات والبلاغات، الحذف).
     - 🔵 **الأزرق (`primary`)**: للأزرار المرتبة والاعتيادية (تعديل، اختيار الليلة، الأقسام والسلاسل، المستخدمين والـ VIP، القائمة، الإذاعة).
     - 🟢 **الأخضر (`success`)**: للأزرار المساندة ونادرة الاستخدام (الإعدادات، ضبط القنوات الـ 7، مزامنة Firebase، المشرفين، الغلاف الديناميكي).
   - **بوت الإرسال (`Vortex Sender`)**: يسلم ملفات الأفلام والمسلسلات والأنمي للمستخدمين مع التحقق من الاشتراك الإجباري والحذف التلقائي بعد 6 ساعات.

2. **3 أقسام رئيسية مستقلة بالكامل:**
   - 🎬 **قسم الأفلام (`movie`)**
   - 📺 **قسم المسلسلات (`tv`)**
   - ⛩️ **قسم الأنمي (`anime`)**

3. **منظومة القنوات المنظمة (3 قنوات خزن + 4 قنوات نشر عام):**
   - **قنوات الخزن السرية (Storage):**
     - قناة خزن الأفلام (`movies_channel_id`)
     - قناة خزن المسلسلات (`series_channel_id`)
     - قناة خزن الأنمي (`anime_channel_id`)
   - **قنوات النشر التلقائي (Publish):**
     - 🔒 **القناة العامة + الاشتراك الإجباري (`@Vortexeo`)**: ينشر فيها تلقائياً كل عمل جديد (فيلم / مسلسل / أنمي).
     - 🎬 **قناة نشر الأفلام**: ينشر فيها تلقائياً بوستات الأفلام الجديدة.
     - 📺 **قناة نشر المسلسلات**: ينشر فيها تلقائياً بوستات المسلسلات والحلقات الجديدة.
     - ⛩️ **قناة نشر الأنمي**: ينشر فيها تلقائياً بوستات وحلقات الأنمي الجديدة.

4. **مولّد الأغلفة الديناميكي الاحترافي (`cover_generator.py`):**
   - يولّد غلاف فيديو عالي الدقة (`1280×720`) يدمج **بوستر الفيلم/المسلسل/الأنمي** مع **حلقة فورتكس النيون المضيئة** وحقوق البوت بخط عربي كوفي عريض ومتصل (`@Vortexeo` و `@Vortexee_Bot`)، ويتحدث تلقائياً حسب تعديلاتك في إعدادات الميني آب أو البوت.
